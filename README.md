## 🚀 Featured Projects

### 🩺 TMed Technology — Graduate Data Science Capstone

An 8-week graduate capstone project applying data science and machine learning to clinical sleep data. Our team investigated factors associated with patient treatment outcomes and communicated our findings to TMed Technology stakeholders.

**Key work:**
- Cleaned and analyzed clinical sleep data
- Conducted exploratory data analysis
- Developed and compared classification models
- Used cross-validation and hyperparameter tuning
- Evaluated models using ROC-AUC, F1 score, sensitivity, specificity, and balanced accuracy
- Analyzed feature importance to identify influential clinical variables

**Tech:** Python · pandas · scikit-learn · Matplotlib
